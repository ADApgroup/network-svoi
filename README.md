# Сайт «Сеть своих» v2 (премиальный, концепция)

Многостраничный статический сайт закрытого международного сообщества. Тёмный «клубный» стиль: малахит, латунь, сургуч; шрифты Forum, Spectral, IBM Plex Mono (Google Fonts).

Юридические разделы, дисклеймеры и политика данных на сайт сознательно не вынесены: эту часть Даниил прорабатывает отдельно с юристом.

## Страницы

| Файл | Что внутри |
|---|---|
| `index.html` | Манифест: печать с девизом «Слово вместо залога», 5 чисел системы, эссе о диаспорах, 10 традиций (Ганза, армянские дома, еврейские общины, ливанцы, гуаньси, марвари, Rotary, YPO, ложи, BNI) и что из каждой взято |
| `how.html` | Устройство: интерактивные кольца (круг → отделение → палата → совет мостов), 5 должностей, 6 механизмов, ритм, правила сдержанности |
| `degrees.html` | 5 ступеней (Гость, Новик, Свой, Поручитель, Старейшина), 8 обрядов, протокол круга на 105 минут, годовой цикл |
| `code.html` | Кодекс из 10 правил (тот же текст, что в боте), интерактивное «принятие кодекса» с печатью, обеты ступеней, совет чести |
| `world.html` | Интерактивная карта: 25 городов в 4 волнах, мосты, фильтр по волнам, как открывается отделение, режимы мостов |
| `path.html` | Путь участника: 8 остановок от карточки до старейшины, линия заполняется при прокрутке |
| `invite.html` | Вход: конверт с сургучной печатью (нажать), 4 шага, что делать без приглашения, вопросы |
| `404.html` | Страница ошибки |

## Сборка

```
python3 _src/build.py                 # пересобрать *.html
python3 _src/build.py --artifact DIR  # плюс копия для превью на claude.ai
python3 _src/bundle.py OUT.html       # весь сайт одним файлом, чтобы переслать
```

Тексты лежат в `_src/content.py`, вёрстка страниц в `_src/build.py`, стили и скрипты в `assets/`. Точки суши на карте (`_src/land-dots.json`) посчитаны из world-atlas 2.0.2 (Natural Earth, public domain).

## Перед публикацией

- В `_src/content.py` заменить `TG_BOT` на ссылку бота-привратника и пересобрать.
- Кодекс (`CODE`) совпадает с `bot/setnet_bot/texts.py`: меняя один, меняйте и другой.
- Сайт закрыт от поисковиков (`noindex`, `robots.txt` Disallow) в духе закрытого клуба. Если нужна индексация, поменять обе настройки.
- Публиковать только `*.html`, `assets/`, `robots.txt`.
